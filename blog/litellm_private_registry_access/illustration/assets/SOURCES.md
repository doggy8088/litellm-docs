# 插圖素材來源 {#illustration-asset-sources}

此資料夾中的素材是原始 SVG。其圖示幾何形狀與顏色均未變更。

## AWS 服務圖示 {#aws-service-icons}

`ecr.svg` 與 `cognito.svg` 直接來自 [AWS Architecture Icons 官方頁面](https://aws.amazon.com/architecture/icons/)，於 2026 年 11 月 11 日下載。該頁面連結至 [2026 年 7 月 31 日的圖示套件](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip)。

原始壓縮檔路徑為 `Architecture-Service-Icons_07312026/Arch_Containers/64/Arch_Amazon-Elastic-Container-Registry_64.svg` 與 `Architecture-Service-Icons_07312026/Arch_Security-Identity/64/Arch_Amazon-Cognito_64.svg`。兩者都使用 80 x 80 的 SVG viewBox。

AWS 擁有這些服務標誌。AWS 的圖示頁面允許客戶與合作夥伴在架構圖以及白皮書、簡報、資料表與海報等材料中使用工具包素材。本出處紀錄記載了該已公布的使用許可；它並未依本 repository 的授權重新授權 AWS 標誌。

插圖嵌入了原始的 AWS 圖示群組，未變更其比例、白色字形或類別顏色。

## LiteLLM 單字標誌 {#litellm-monogram}

`litellm.svg` 是本 repository 的 `static/img/brand/litellm-monogram-blue.svg` 的逐位元組複本，也用於 `blog/cache_aware_routing/animation/assets/litellm.svg` 的快取感知路由動畫。它使用既有的 LiteLLM 品牌藍色 `#0117be` 與 `0 0 372.14 371.53` 的 SVG viewBox。深色模式使用來自 `static/img/brand/litellm-monogram-white.svg` 的白色填色，幾何形狀相同。所有權與既有的 repository 條款維持不變。
